# Real-Time Lakehouse Platform

A production-style real-time data engineering project built with:

- Apache Kafka
- Apache Flink
- Apache Iceberg
- Apache Spark
- Docker

## Architecture

Python Data Generator
→ Kafka
→ Flink
→ Apache Iceberg
→ Apache Spark

## Project Goals

This project demonstrates:

- Real-time event ingestion
- Event-time processing
- Watermarks
- Deduplication
- Window aggregation
- Apache Iceberg storage
- Spark analytics
- Failure injection

## Business Scenario

The platform simulates real-time aircraft telemetry data including
temperature, sensor readings, flight information, and event timestamps.
